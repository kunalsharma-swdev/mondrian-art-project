# mondrian-art-project
A simple recreation of Piet Mondrian-style abstract art using HTML and CSS Grid/Flexbox.


<h1>PREVIEW</h1>

This project creates a geometric art composition inspired by the works of Piet Mondrian using colored blocks, clean lines, and structured layouts.

Features
Pure HTML & CSS
Responsive layout
Uses CSS Grid/Flexbox
Beginner-friendly project
Inspired by modern abstract art
Technologies Used
HTML5
CSS3
